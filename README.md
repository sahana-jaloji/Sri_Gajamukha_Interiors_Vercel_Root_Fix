# Sri Gajamukha Interiors & Constructions — Website

A multi-page static website built with HTML, CSS, JavaScript and a small Node.js development server. The project is ready for Vercel static deployment.

## Run locally
1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run `npm start`.
4. Visit http://localhost:3000.

## Deploy to Vercel
1. Extract the ZIP.
2. Import the project folder into a Git repository, or upload it through Vercel's supported deployment workflow.
3. In Vercel, choose **Other** as the framework preset.
4. Leave the build command empty (or use `npm run build`) and set the output directory to `.`.
5. Deploy.

## Enquiry form
